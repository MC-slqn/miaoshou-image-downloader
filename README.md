# 妙手商品图片下载器

用于妙手 ERP TikTok 采集箱的油猴脚本。只收集商品编辑窗口里的 **产品图片** 和 **产品描述**，分区预览、勾选，并按分类保存到本地。

适用页面：<https://erp.91miaoshou.com/tiktok/collect_box/items>

这是独立社区项目，与妙手 ERP 无隶属关系。目前版本 **1.2.0**，采用 [MIT 许可证](LICENSE)。

## 功能

- 下载面板分为“产品图片”和“产品描述”两个区域，支持各区独立全选、取消、搜索和逐张勾选。
- 选择本地总目录，在网页文件夹下建立两个分类子目录；也可下载相同结构的 ZIP。
- 各分类从 `0001` 独立编号；同一图片在两个栏目中可以分别保存。
- 排除列表图、头像、SKU 图片、工具按钮和隐藏商品窗口；找不到目标栏目时提示，不采集整页。
- 下载前检查商品是否发生变化；支持停止、失败提示及重名文件添加后缀。
- 单文件，无运行时第三方库，无遥测或图片上传功能。

```text
你选择的总目录/
└── 商品名称或货号/
    ├── 产品图片/
    │   ├── 0001_cover.jpg
    │   └── 0002_side.webp
    └── 产品描述/
        ├── 0001_detail.jpg
        └── 0002_features.png
```

## 安装和使用

**[点击安装脚本](https://raw.githubusercontent.com/MC-slqn/miaoshou-image-downloader/main/miaoshou-image-downloader.user.js)**（需先启用脚本管理器）。

1. 在浏览器中安装并启用 Tampermonkey 或 Violentmonkey。
2. 打开本仓库的 [miaoshou-image-downloader.user.js](miaoshou-image-downloader.user.js)，点击 **Raw**；如果没有弹出脚本安装页面，在脚本管理器中新建脚本，粘贴完整代码并保存。
3. 更新旧版时，编辑原脚本并完整替换代码，避免同时运行多份。
4. 刷新妙手采集箱页面，打开一个商品的编辑窗口，等待图片加载，点击右下角“下载图片”。
5. 在两个区域勾选图片，填写网页总文件夹名称，选择保存目录，再点击“保存到文件夹”。也可以选择“打包下载 ZIP”。

直接选择目录需要支持文件系统访问 API 的浏览器，例如桌面版 Edge/Chrome，并由用户授权。其他环境可尝试 ZIP。ZIP 的下载位置由浏览器设置决定。

同一个采集箱网址可以编辑多个商品，**请手动把网页总文件夹名称改成商品名称或货号**；目前不自动识别商品名称。目录选择只在本次标签页运行中保留，刷新后需要重新选择。按钮距底部 76px。

更多操作与限制见 [使用说明](使用说明.md)。

## 当前限制

- **图片中文字翻译、马来语转换和 OpenAI 接口尚未实现。** 当前脚本仅负责选择和下载图片。
- 网站更新可能改变 DOM 结构，届时需要更新栏目选择器。
- 描述优先使用编辑器正文，正文无法读取时尝试同一栏目的缩略图并提示；跨域编辑器或防盗链可能造成图片缺失或下载失败。
- ZIP 采用无压缩存储，单包图片内容最多 512 MB。图片较多时请分批下载或直接保存到目录。
- 已有文件不自动整理；并发向同一目录写入可能冲突，请避免多标签页同时保存。

## 权限与隐私

脚本仅匹配 `https://erp.91miaoshou.com/tiktok/collect_box/*`，使用 `GM_xmlhttpRequest` 获取选中的图片，使用 `GM_registerMenuCommand` 注册菜单。`@connect *` 允许图片来自不同 CDN；实际请求地址来自目标栏目的图片候选地址。打开面板会请求图片预览。

没有后端服务、API 密钥、统计代码或账号接口调用。保存目录由浏览器选择器授权。请遵守图片权利人的授权和网站条款。

## 开发和验证

需要 Node.js 20 或以上版本：

```sh
npm ci
npx playwright install chromium
npm test
```

Linux 环境可用 `npx playwright install --with-deps chromium` 安装浏览器及系统依赖。已有兼容浏览器时，也可设置环境变量 `BROWSER_PATH` 为其可执行文件的完整路径。

测试在独立的本地模拟页面运行，不访问真实账号。覆盖栏目过滤、两个下载分区、目录写入、独立编号、跨区重复图片、切换商品检查，以及 ZIP 目录结构和 CRC。测试产物保存在被 Git 忽略的 `test-results/`。

目录选择器与 GM 请求使用测试适配器，文件写入使用浏览器私有文件系统。这不能替代真实网站及脚本管理器中的兼容性验证；尚未完成登录后的真实商品页面验证。
